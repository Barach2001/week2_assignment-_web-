# My Budget Tracker — Week 2 Assignment

## What I built
I extended the Budget Tracker project with an expense table, an improved expense form, multimedia content, and a collapsible help section. The page is built with HTML and CSS.

## Project files
- **index.html** — contains the page structure, expense form, sample expense table, image, embedded video, and help section.
- **style.css** — controls the layout, colors, spacing, responsive design, table styling, hover effects, and form focus styles.
- **README.md** — explains the project and the role of each file.

## Features
1. An expense table with Name, Amount, Category, and Date columns and five sample records.
2. An expense form with name, amount, category, and date fields. The category dropdown has Food, Transport, Rent, Entertainment, and Other.
3. A logo image and an embedded YouTube video.
4. A collapsible “How to use this tracker” section using HTML details and summary elements.
5. CSS selectors and states including a descendant selector, a direct child selector, `:nth-child(even)`, `:not()`, `:focus`, and `:hover`.
6. A responsive layout for smaller screens.

## How to view the project
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Keep `style.css` in the same folder so the styles load correctly.

## Note
The Add Expense button is intentionally set to `type="button"` and does not add records yet. JavaScript functionality will be introduced in a later week.
